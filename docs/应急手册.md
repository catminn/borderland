# 百鬼夜行 · 活动当天应急手册

> 原则：**先保住游戏继续，再补数据。** 网站是辅助，现场秩序以工作人员为准。服务器上的状态不会因为断网丢失；恢复后以服务器为准。

## 0. 赛前准备（10/13 彩排时一起演练）

- [ ] 总控、Dealer、判官、孟婆、黑白无常、大屏各备**一部带热点的手机**（或确认能用蜂窝数据）。网站不依赖场地 Wi‑Fi，用蜂窝数据也能登录。
- [ ] 总控在**活动前**用「总控工具 → 应急记录表 → 下载空白记录表」下载空白表，**打印 3 份**放在总控桌、判官桌、大屏旁；同时把 HTML 文件存在总控电脑和手机里。
- [ ] 所有工作人员的 PIN 卡（含 `?pin=` 二维码）打印一份纸质备份，放总控处。
- [ ] 对讲机或微信群（工作人员）确认可用，约定**暗号频道**：只用于应急。
- [ ] **每台设备（工作人员、玩家）活动前正常联网打开网站两次并登录一次**：第一次安装离线缓存，第二次把字体和图片也缓存下来。之后即使网站打不开，用同一个浏览器重开也能看到页面和最后一次同步的状态（页头显示「离线 · 最后同步 HH:MM」，不能操作）。不要用无痕模式，也不要清除浏览器数据。
- [ ] 总控每 **15–20 分钟**点一次「导出当前状态」，文件留在电脑里（断网后它就是最新的纸面快照）。
- [ ] 彩排时做一次「断网演练」：关掉总控 Wi‑Fi，按下面 B 级流程走一遍。

## 1. 先判断是哪一级

| 级别 | 现象 | 做法 |
|---|---|---|
| A 个别设备 | 一个人手机没电、卡住、网络差 | 换设备，用**同一个 PIN** 重新登录（PIN 不绑设备）；数据在服务器，不会丢 |
| A 个别角色掉线 | 网页显示未连接 | 页面会自动重连（60 秒无响应也会重连）；等 1 分钟，仍不行就刷新或换蜂窝数据 |
| B 场地网络差 | 多人同时掉线、操作延迟 | 全体工作人员**关 Wi‑Fi 改用蜂窝数据**；玩家同样 |
| C 网站整体不可用 | Cloudflare 故障、全场连不上 | **切纸质**（见 §2），总控每 10 分钟汇总一次 |

## 2. C 级：切纸质流程

1. 总控宣布「切纸质」（对讲机 + 现场口头）。**暂停计时**也在纸上写下切换时的游戏时间（总控页能看到的最后一个时间，或看记录表里的「导出于 / 游戏时间」）。
2. 总控打开**最近一次导出的记录表**（电脑里的 HTML，离线可用）；没有就用打印的空白表，把各队冥币、花色、存活人数按最后所知填上。
3. **记录表按角色分页，各人打印自己那一页**（总控、8 个房间各一页、黑白无常 / 孟婆、判官、规则速查）。每一页都是「一件事一行」的流水：时间 + 队伍 / 编号 + 结果，后面的空行继续写：
   - **Dealer（自己的房间那一页）**：每队挑战一行——队伍、进入时间、结束时间、胜 / 负 / 中途离开、得分、淘汰者编号。输了抽签淘汰 1 人，**立刻用对讲机报黑白无常和总控**：「3♠ 红队 负，淘汰 R-03」。页底可记预约 / 排队。
   - **黑白无常 / 孟婆（共用一页「淘汰名单」）**：只写**当前不在场的人**，一人一行，随流程补全：淘汰时间、位置、接到时间、入鬼市时间、鬼市冥币合计（凑够 500 买命）、复活时间；复活后把这行划掉或备注「已复活」。在场的人不用记。
   - **判官**：任务记录一件事一行（鬼门开 / 任务完成 / Scavenger 兑换 / 勾魂令）；下面有每队 Scavenger 额度表（每题 100 分，10 分钟最多 2 题，每队最多 600 分）。
   - **总控**：队伍总表（导出时冥币 + 「当前冥币」继续改写、花色、已通关房间）和**冥币流水**（时间、队伍、原因、变动 ±、变动后）。汇总所有人的口头 / 纸面汇报；大屏位置改放总表。
4. 规则照常：赢房 n×100 + 花色，输房淘汰 1 人；鬼市线 500；鬼门开期间暂停预约与入场；预约 2 分钟失效（纸质期间由 Dealer 口头管）。
5. 记录表在浏览器里**可以直接继续填写**（自动保存在该设备）；也可以打印后手写。填的时候**每件事写时间**，方便补录。

## 3. 恢复后补录

1. 总控登录网站，打开「总控工具」，先**导出当前状态**（留作对照），再看服务器状态停在哪一刻。
2. 对照纸质记录，只补**服务器没有的变化**（总控按冥币流水，Dealer 按自己房间的记录，黑白无常 / 孟婆按淘汰名单）：
   - 冥币：生死簿 → 修改队伍 → 改冥币（`setscore`）。
   - 淘汰 / 鬼市 / 复活：由对应角色（黑白无常、孟婆）在各自页面补点。
   - 房间结果：Dealer 在自己页面补「结算」。
   - 花色、已通关：随 Dealer 补结算自动生成；若无法补，总控改冥币并在备注写清。
3. 补完后让总控**导出一次**，与纸质总表核对（冥币、存活人数、花色）。
4. 活动结束后：下载 PIN 表、统计 CSV、最后一次导出；然后删 DEV_PIN、清空统计、下线（见 CLAUDE.md §6、§7.17）。

## 4. 常见情况速查

- **总控页面刷新不出来**：先用已打开页面里的「导出当前状态」，不要刷新；换蜂窝数据再试。已事先打开过的设备，重开页面也能看到最后状态并导出（只读）。
- **离线显示的限制**：只显示该账号最后一次同步的内容，计时是冻结的、不代表真实时间；所有操作都要服务器确认，离线时点不了。连上服务器后自动换回实时状态。
- **只有大屏坏了**：换任意设备登录大屏 PIN，全屏即可。
- **某个房间的 Dealer 手机坏了**：Dealer PIN 绑定的是房间，不是设备；备用手机输同一个 PIN 即可。
- **服务器数据疑似错误**：总控工具 → 备份与恢复（每 10 次操作自动备份，恢复前会先备份当前数据）。

## 5. 导出功能说明

- **每个工作人员**（Dealer、判官、孟婆、黑白无常、总控）页头都有「导出记录表」：只导出**自己负责的部分**（Dealer = 自己绑定的房间；黑白无常、孟婆 = 淘汰名单；判官 = 判官页；另附规则速查），已发生的记录预填好，后面留空行继续写。**总控**导出全部：只有总控自己那页留空行，其他角色的页只有已发生的记录（没有就显示「暂无记录」）。建议每人每 15–20 分钟导出一次。
- 「总控工具 → 应急记录表 → 导出当前状态」（与总控的页头按钮相同）：在**本机**生成 HTML，**不联网**。页面已打开且曾同步过状态时，断网后仍可点，导出的是最后一次同步的状态。
- 「下载空白记录表」：同样本机生成，全部角色页都带空行，供打印。
- 导出的 HTML 自包含，离线双击即可打开；可打印（A4 横向），也能直接填写，内容自动保存在**这台设备、这个浏览器**里（换浏览器不会带过去，请打印或另存）。
- 已打开的页面不需要网络就能导出；已经下载下来的记录表文件也不需要网络。

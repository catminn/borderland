# 百鬼夜行 · 活动当天应急手册

> 原则：**先保住游戏继续，再补数据。** 网站是辅助，现场秩序以工作人员为准。服务器上的状态不会因为断网丢失；恢复后以服务器为准。

## 0. 赛前准备（10/13 彩排时一起演练）

- [ ] 总控、Dealer、判官、孟婆、黑白无常、大屏各备**一部带热点的手机**（或确认能用蜂窝数据）。网站不依赖场地 Wi‑Fi，用蜂窝数据也能登录。
- [ ] 备几张白纸和笔放在总控桌、判官桌、每个房间（网站整体打不开时手写用）。
- [ ] 用「总控工具 → 下载 PIN 表」拿到每位玩家的 PIN 和登录链接，自行制作身份卡（网站不再提供打印）。签到时发卡，玩家打开网址输入 PIN 即登录。
- [ ] 所有工作人员的 PIN 卡（含 `?pin=` 二维码）打印一份纸质备份，放总控处。
- [ ] 对讲机或微信群（工作人员）确认可用，约定**暗号频道**：只用于应急。
- [ ] **每台设备（工作人员、玩家）活动前正常联网打开网站两次并登录一次**：第一次安装离线缓存，第二次把字体和图片也缓存下来。之后即使网站打不开，用同一个浏览器重开也能看到页面和最后一次同步的状态（页头显示「离线 · 最后同步 HH:MM」，不能操作）。不要用无痕模式，也不要清除浏览器数据。
- [ ] 彩排时做一次「断网演练」：每个工作人员关掉网络记几条「离线记录」，再连上点「一键补录」。也可以先用开发者 / 展示 PIN 在「总控工具 → 模拟离线」里演示一遍。

## 1. 先判断是哪一级

| 级别 | 现象 | 做法 |
|---|---|---|
| A 个别设备 | 一个人手机没电、卡住、网络差 | 换设备，用**同一个 PIN** 重新登录（PIN 不绑设备）；数据在服务器，不会丢 |
| A 玩家手机打不开 | 玩家看不到自己的金币 / 通知 | **不影响游戏**：所有改变分数的操作都在工作人员手上。玩家去问最近的工作人员（总控生死簿能查任何人）；抽奖只看金币、花色和房间成绩，不需要玩家操作手机 |
| A 个别角色掉线 | 网页显示未连接 | 页面会自动重连（60 秒无响应也会重连）；等 1 分钟，仍不行就刷新或换蜂窝数据 |
| B 场地网络差 | 多人同时掉线、操作延迟 | 全体工作人员**关 Wi‑Fi 改用蜂窝数据**；玩家同样 |
| C 网站整体不可用 | Cloudflare 故障、全场连不上 | **切纸质**（见 §2），总控每 10 分钟汇总一次 |

## 2. C 级：网站整体不可用

1. 总控宣布「切纸质」（对讲机 + 现场口头），在纸上写下切换时的游戏时间。
2. **已经打开过网站的设备**：重开页面仍能看到最后一次同步的状态（只读，页头显示「离线 · 最后同步 HH:MM」），谁的金币、花色、谁在鬼市都能查。
3. **页面还开着的工作人员**：照常在页面顶部的「离线记录」里记（见 §3）。**页面打不开的**：在白纸上一件事一行，写「时间 + 编号 + 结果」（Dealer 写胜 / 负；黑白无常 / 孟婆写接到 / 入鬼市 / 复活方式（赎人写出钱人编号）；判官写解谜题和鬼门开奖励）。输了的人原地等，**立刻用对讲机报黑白无常**：「♠4 编号 017 失败」。
4. 规则照常：赢房 n×100 + 花色，输了进鬼市；鬼市用实体筹码（领 200，赢到 500 自赎，待满 15 分钟不管赚没赚到都能复活），和金币完全不互通；房间默认不限人数。
5. 总控不用记，汇总口头汇报、维持秩序即可。

## 3. 离线记录与一键补录（谁断网谁记，连上后自己补）

1. **页面还开着、只是断网**：断线 5 秒后，Dealer / 判官 / 孟婆 / 黑白无常的页面顶部会出现「离线记录」。照常在这里记（下拉 / 按钮选，编号可一次填多个），记录存在这台设备上，刷新也不丢。
   - Dealer：编号 + 赢 / 输（房间自动是自己那间）。
   - 黑白无常：编号 + 抓到了 / 送入鬼市。
   - 孟婆：编号 + 入鬼市 / 自赎 / 被别人赎（填出钱人编号）/ 复活（筹码是实体的，网站不记）。
   - 判官：编号 + 解谜题（填谜题编码）/ 鬼门开奖励（+300 / 救一个人 / 拿一个花色）。
2. **连上之后**：同一个位置出现「**一键补录 N 条**」，点一下就补进服务器。补之前服务器自动备份（「备份与恢复」里叫「离线补录前」），补错了可以恢复。
3. 补录**不按规则拦**（时间、房间状态、鬼市截止都不管），记了什么就补什么；只防重复：同一人同一间房已成功过不再加分，同一题不重复兑换。没补上的那几条（比如编号写错）会留在列表里、标出原因，改好再点一次。
4. **页面打不开**（手机没电、网站整体挂了）：先记在纸上；连上后照着纸上的记录，在自己页面上正常操作补上（金币对不上的，总控在生死簿里改并写原因）。
5. 总控不用记：断网时导出一份「当前状态」留作对照即可。
6. 活动结束后：下载 PIN 表、统计 CSV、最后一次导出；然后删 DEV_PIN、清空统计、下线。

## 4. 常见情况速查

- **总控页面刷新不出来**：先用已打开页面里的「导出当前状态」，不要刷新；换蜂窝数据再试。已事先打开过的设备，重开页面也能看到最后状态并导出（只读）。
- **离线显示的限制**：只显示该账号最后一次同步的内容，计时是冻结的、不代表真实时间；正常按钮离线时点不了，要记的事写进页面顶部的「离线记录」。连上服务器后自动换回实时状态。
- **只有大屏坏了**：换任意设备登录大屏 PIN，全屏即可。
- **某个房间的 Dealer 手机坏了**：Dealer PIN 绑定的是房间，不是设备；备用手机输同一个 PIN 即可。
- **服务器数据疑似错误**：总控工具 → 备份与恢复（每 10 次操作自动备份，恢复前会先备份当前数据）。
